# Topic 5 - N8N LMS Assessment
## Building API Workflows in n8n

## 1. Assessment Overview

This assessment evaluates your ability to build sequential multi-node API workflows in n8n using dynamic expressions, ancestor node references, context variables, runtime headers, timestamps, and execution logs.

## 2. Assessment Objective

Demonstrate your ability to create multi-node API workflows, map data between nodes, use dynamic expressions, generate runtime headers and timestamps, and validate execution results.

## 3. Prerequisites

- Review the Requirement Document.
- Review the Implementation Guide.
- Complete Topics 1–4.
- Access an active n8n instance and public REST APIs.

## 4. Assessment Tasks

- Exercise 1 – Build a multi-node workflow.
- Exercise 2 – Use $json and ancestor node expressions.
- Exercise 3 – Configure dynamic HTTP headers and ISO-8601 timestamps.
- Exercise 4 – Map execution/workflow context variables and verify execution logs.
- Exercise 5 – Record a demo video, upload the workflow/source code, and submit through the LMS.

## 5. Practical Assessment Checklist

- [ ] Multi-node workflow created
- [ ] $json expressions used
- [ ] Ancestor node references configured
- [ ] Dynamic headers implemented
- [ ] ISO-8601 timestamps generated
- [ ] Context variables mapped
- [ ] Execution logs verified
- [ ] Workflow executed successfully
- [ ] Demo video recorded

## 6. Assessment Success Criteria

- Build a sequential API workflow.
- Correctly reference parent and ancestor node data.
- Generate dynamic headers and timestamps.
- Use execution context variables.
- Validate workflow execution.
- Submit all required deliverables.

## 7. Required Deliverables

- Loom/YouTube Demo Video – Mandatory
- GitHub Public Repository or Exported n8n Workflow – Mandatory
- Complete Workflow/Source Files – Mandatory
- Screenshots of workflow execution and logs – Mandatory
- Supporting Documentation (PDF/DOCX) – Optional
- Description / Additional Comments – Recommended

## 8. Submission Guidelines

Submit a Loom/YouTube walkthrough demonstrating the complete workflow, dynamic expressions, ancestor references, execution logs, and runtime variables. Include the exported workflow or GitHub repository, screenshots, and implementation notes.

## 9. Final Submission Checklist

- [ ] Completed all assessment tasks
- [ ] Verified workflow execution
- [ ] Uploaded workflow/repository
- [ ] Uploaded demo video
- [ ] Reviewed all deliverables

## 10. Important Note

Ensure your demo video, workflow or GitHub repository, screenshots, documentation, and comments are included before submission. Incomplete submissions may not be evaluated.
